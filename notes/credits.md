The three `texture` files are the colour maps of those Poly Haven textures turned to grey and scaled to 256 pixels, so the cloth colour of each spine shows through. The two `about-library-interior` files are the same photo resized to 800 and 1400 pixels wide and used in the hero. The library in this project is fictional, so the photo shows a real library that is not related to it.

## Fonts

## Code

The board under the books (top, front edge and shadow) follows the look of the CodePen bookshelf by ekfuhrmann (https://codepen.io/ekfuhrmann/pen/OJmRVPj). The CSS is rewritten for this project and only the idea and the shape are taken.

The "stairs" and "pyramid" patterns on some spines come from Lea Verou's CSS3 Patterns Gallery (https://projects.verou.me/css3patterns/).
